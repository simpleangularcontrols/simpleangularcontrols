## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in **SimpleAngularControls**, please report it using GitHub’s **private vulnerability reporting**:

1. Go to the **Security** tab of this repository.
2. Click **“Report a vulnerability”**.
3. Include details such as steps to reproduce, expected vs. actual behavior, affected version, and any relevant logs or screenshots.

**Timeline**

- We will acknowledge your report within **48 hours**.
- Updates will be provided **weekly** until the issue is resolved.

**Resolution & Disclosure**

- Fixed vulnerabilities will be communicated through GitHub with the patched version.
- Please do **not publicly disclose** issues until they are resolved.
- Responsible reporting may be acknowledged in release notes.
